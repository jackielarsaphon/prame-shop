# PRAME DESIGN — หน้าเว็บ HTML + CSS

## วิธีเปิด
1. แตกไฟล์ ZIP ก่อน
2. เปิดโฟลเดอร์ `prame-shop`
3. ดับเบิลคลิก `index.html` เพื่อเปิดใน Chrome, Edge หรือ Firefox

เปิดได้แบบออฟไลน์ ไม่ต้องติดตั้ง Node.js หรือโปรแกรมเพิ่มเติม

## ไฟล์สำคัญ
- `index.html` — โครงสร้างหน้าเว็บและการ์ดสินค้าทั้ง 12 ใบ
- `styles.css` — สี ฟอนต์ CSS Grid และขนาดสำหรับคอม/แท็บเล็ต/มือถือ
- `script.js` — JavaScript เพิ่มการทำงานให้ปุ่ม Details, Buy และ Contact
- `assets/` — รูปสินค้า โลโก้ และฟอนต์ที่ใช้ในเว็บ

## วิธีแก้ไข
- ชื่อสินค้าและราคา: แก้ข้อความใน `index.html`
- รายละเอียดและราคาของตะกร้า: แก้ `products` ใน `script.js` (ราคาใช้หน่วยเซนต์ เช่น 4999 = $49.99)
- สีและระยะห่าง: แก้ตัวแปรใน `:root` ของ `styles.css`
- รูปสินค้าและโลโก้: เปลี่ยนไฟล์ภาพใน `assets/`
- ข้อมูลติดต่อ: แก้ส่วน `contact-link` ท้าย `script.js`

หน้าตาเว็บใช้ HTML และ CSS ล้วน JavaScript เป็นส่วนเสริมสำหรับทดลองกดปุ่ม
ตะกร้าเป็นตัวอย่างในหน้าเว็บ ไม่มีการส่งคำสั่งซื้อหรือรับชำระเงินจริง และจะเริ่มใหม่เมื่อรีเฟรชหน้า
